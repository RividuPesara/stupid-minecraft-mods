# bucket-everything

Use an empty bucket on a mob to scoop it up. Use the filled bucket on a block to let it back out, exactly as it was (health, name, villager trades, tamed owner and so on).

Works on passive mobs, villagers, golems and hostile mobs, including the Wither, the Warden and the elder guardian. The Ender Dragon can't be bucketed. Fish, axolotls and tadpoles keep their normal water bucket behaviour.

Cows, mooshrooms and goats need sneaking, so a normal click still milks them.

## Advancements

The mod adds its own advancement tab:

| Advancement | How to get it |
|---|---|
| Bucket Everything | Bucket any mob |
| Reverse Uno | Let a bucketed mob back out |
| Portable Explosive | Bucket a creeper |
| Not Like This | Bucket a charged creeper |
| Landlord | Bucket a villager |
| Heavy Metal | Bucket an iron golem |
| Happy Little Bucket | Bucket a happy ghast |
| Big Fish | Bucket an elder guardian |
| Shh... | Bucket the Warden |
| Pocket Boss | Bucket the Wither |
| Gotta Bucket 'Em All | Bucket every kind of mob |

## Setup

Requires JDK 25. Run `./gradlew build` to build the jar, or `./gradlew runClient` to start the game with the mod.
